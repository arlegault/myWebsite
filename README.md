# alexlegault.com

Personal site for Alex Legault. Plain HTML, CSS, and images. There is no build step.

## Publish

Upload this directory to S3 as-is. `index.html` is at the root, next to the other pages, `mystyle.css`, `favicon.svg`, `sitemap.xml`, `robots.txt`, and the images.

## Unpublished pages

Essay drafts stay out of the navigation, the writing index, and `sitemap.xml`. The writing page keeps those links commented out. `consulting.html` stays unlinked the same way.
